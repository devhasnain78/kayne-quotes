🎤 Kanye Quotes Generator
=========================

A Python application that fetches and displays random Kanye West quotes using the Kanye Rest API. Features a clean, responsive graphical interface built with Tkinter for an interactive user experience.

Features
--------

Fetches real-time quotes from the external Kanye Rest API to display random Kanye West quotes. Implements a clean graphical user interface with Tkinter including responsive buttons and formatted text display. Features one-click quote generation with error handling for API connectivity issues and network failures.
